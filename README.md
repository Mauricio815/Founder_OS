# Founder OS Skills para Houston

Paquete de skills estratégicos para ayudar a un fundador a validar una idea, posicionarla, construir su modelo de negocio, diseñar marketing y go-to-market, y gestionar crecimiento con evidencia.

## Skills incluidas

1. **Founder OS** — diagnostica la etapa, identifica el cuello de botella y coordina las demás skills.
2. **Idea Validation** — valida problema, solución y señales reales de demanda.
3. **Positioning** — define cliente ideal, alternativas, categoría y diferenciación.
4. **Business Model** — diseña oferta, pricing y economía unitaria.
5. **Marketing Brand** — convierte el posicionamiento en mensajes, contenido y adquisición.
6. **Go To Market** — diseña segmento inicial, canales, lanzamiento y proceso comercial.
7. **Growth Analytics** — diagnostica embudo, retención y experimentos de crecimiento.

## Importar en Houston

### Opción recomendada: importar una por una

1. Abre el agente donde quieras instalar Founder OS.
2. Ve a **Skills** y elige **Import**.
3. Descarga e importa los archivos `.skill` de la carpeta [`dist/`](dist/).
4. Importa primero `founder-os.skill` y después las seis skills especializadas.

Cada archivo de `dist/` es un paquete independiente listo para importar.

### Instalar el paquete completo desde el repositorio

Copia el contenido de `.agents/skills/` dentro de la carpeta de skills del workspace del agente. La estructura ya coincide con el formato esperado por Houston.

## Configuración inicial

La skill **Founder OS** incluye plantillas para crear:

- `company/overview.md`
- `company/idea.md`
- `company/validation.md`
- `company/positioning.md`
- `company/business-model.md`
- `company/marketing.md`
- `company/go-to-market.md`
- `company/growth.md`

Al usarla por primera vez, pide: **“Configura Founder OS para mi empresa”**. El agente ofrecerá crear los documentos y solicitará aprobación antes de guardarlos.

## Principios

- No inventa hechos, cifras, clientes ni evidencia.
- Separa hechos, supuestos, incógnitas y recomendaciones.
- Propone experimentos pequeños antes de escalar.
- El fundador conserva todas las decisiones.
- Solo guarda cambios después de recibir aprobación.
